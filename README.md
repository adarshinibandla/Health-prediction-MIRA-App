# Health Prediction MIRA App 🩺

This is a simple AI-based Health Prediction application built using Python and Streamlit.

## Features
- Add patient records
- Update patient records
- Delete patient records
- View all records
- Health risk prediction based on glucose and cholesterol levels
- Email validation
- SQLite database for data storage

## Tech Stack
- Python
- Streamlit
- SQLite

## How to Run

1. Install dependencies:
 pip install -r requirements.txt
2. Run the app:
 streamlit run app.py
